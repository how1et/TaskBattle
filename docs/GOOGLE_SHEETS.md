# Настройка экспорта в Google Таблицы

Экспорт работает из Cloudflare Worker, независимо от ИИ-сессии. Ученикам не нужен Google-аккаунт. Нужен один подтверждённый владельцем документ; программа не ищет таблицу по названию и не создаёт отдельные файлы на каждую попытку.

## Действия владельца

1. Создайте Google-таблицу «Результаты TASKBATTLE» в своём аккаунте. Скопируйте её ссылку. ID — часть адреса между `/d/` и `/edit`.
2. В своём Google Cloud project включите **Google Sheets API**. Создайте отдельный service account только для этого экспорта. Не включайте domain-wide delegation. Не подключайте платные тарифы/биллинг для этой задачи.
3. Откройте настройки доступа этой конкретной таблицы и добавьте `client_email` служебного аккаунта как редактора. Открывать документ всем по ссылке не требуется.
4. Создайте ключ служебного аккаунта в формате JSON. Внесите весь JSON напрямую в **серверный secret** `GOOGLE_SERVICE_ACCOUNT_JSON` в настройках текущего Site. ID документа задайте как `GOOGLE_SPREADSHEET_ID`. Ключ не передавайте в чат, не добавляйте в Git, публичные переменные или клиентский код. Удалите загруженную копию после безопасного сохранения секрета согласно правилам вашей организации.
5. Опубликуйте версию с обновлённой конфигурацией. Откройте завершённую попытку по секретной ссылке преподавателя → «Сохранить результаты» → формат → подтвердить. Проверьте заголовок, строки и ссылку на лист. Повторите сохранение: URL должен остаться тем же.

Для локальной проверки можно положить эти значения в игнорируемый `.dev.vars` (никогда не публиковать). Основное приложение без Google продолжает работать; кнопка экспорта показывает понятную ошибку настройки. Подключение Google Drive к ИИ само по себе не даёт опубликованному Worker постоянный доступ.

Если ключ отозван или истёк организационный доступ, обновите secret. Если таблица недоступна, проверьте ID и права её редактора. При 429 подождите минуту. После сетевой ошибки повторите сохранение: уже созданный лист будет найден по его ID и метке.

## Авторизация и надёжность

Worker подписывает service-account JWT алгоритмом RS256 через WebCrypto, получает краткоживущий access token со scope `https://www.googleapis.com/auth/spreadsheets` и кэширует его до истечения. Ключи/JWT/access tokens не выводятся в диагностику. Секрет преподавателя проверяется до работы с Google; ответы, фото и capability-ссылки не экспортируются.

В D1 заранее сохраняется уникальная пара `(attempt_id, format)`, document ID, случайный положительный sheet ID, уникальная метка и неизменяемый пакет содержимого. Один Google `batchUpdate` атомарно добавляет лист, ячейки, форматирование и developerMetadata. Пользовательские строки передаются как `stringValue`, никогда как формулы. Время — `numberValue` секунд с форматом `0.0`.

Перед повтором и после неопределённой ошибки программа ищет именно sheet ID с собственной меткой. Это восстанавливает потерянный HTTP-ответ и сбой записи статуса в D1 после успешного Google batch. Совпадение ID без нашей метки возвращает ошибку и не изменяет чужой лист. Новые ID при неопределённом результате не выдаются. Если пользователь сам удалил экспортированный лист, сохранённая ссылка не создаёт его заново; автоматической перезаписи/восстановления чужих изменений нет.

AMC8 использует 25 номеров подборки, без распознавания официальных номеров и олимпийского балла. Свободная форма содержит только принятые ответы, включая неверные, и отдельное время неотправленных задач. Пустые темы остаются пустыми. Год запрашивается в диалоге, если не указан в комнате.

Через 72 часа локальный результат и его соответствие экспорта очищаются. **Google-лист остаётся**: cleanup не обращается к Google и не содержит удаления листов.

Официальные источники: [service-account OAuth](https://developers.google.com/identity/protocols/oauth2/service-account), [атомарные batch-запросы](https://developers.google.com/workspace/sheets/api/guides/batch), [developer metadata](https://developers.google.com/workspace/sheets/api/guides/metadata), [форматы ячеек](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/cells).

## Проверка без Google-доступа

`tests/lifecycle.test.mjs` использует настоящую обработку маршрута, временную SQLite D1 и реальную подпись временным RSA-ключом в памяти. Только ответы Google API заменены тестовым транспортом. Проверяются teacher ACL, настройки, 25 строк AMC8, неполная подборка, нулевой свободный отчёт, числовое время, literal text, потеря подтверждения и повтор без дублей. Это не заменяет проверку реального листа в согласованном документе.
