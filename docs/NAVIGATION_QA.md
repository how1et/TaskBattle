# Проверка свободной навигации и экспорта — 28 сентября 2026

## Автоматически

65 тестов: прежние 55 плюс проверки новой модели и форматов. Настоящие TS-модули маршрутов выполняются с SQLite, повторяющей атомарные batch D1, и управляемым R2. Проверены:

- 1 → 5 → 2 → 5: отдельные интервалы, повтор close без удвоения, независимые текст и File-черновики при отказе локального хранилища.
- Последний номер при пропусках; обновление ответа без новой строки; поздний повтор старого request ID не откатывает новую редакцию.
- Ошибка R2 до/после записи; потеря подтверждения D1; двойная отправка; сохранение/удаление принятого фото; отмена во время загрузки.
- Владение одним интервалом, takeover по checkpoint, запрет позднего close, timeout без добавления технического ожидания.
- Полный проход всех 25 задач в произвольной последовательности, ручное и календарное завершение, сохранение готовых legacy-отчётов и перенос активной legacy-попытки.
- Teacher ACL экспорта; AMC8 25 строк и неполная подборка, свободные исходные номера, ноль ответов, пустые темы, запрос отсутствующего года, literal user text, числовые секунды.
- Временная реальная RSA-подпись и имитация Google API: потерянное подтверждение, повтор без нового листа, сохранность внешнего листа после cleanup.

- Созданы пять задач загрузкой через форму; название, год 2025, тема первой задачи; скопирована ссылка; ученик стартовал в отдельной вкладке.

- Reload восстановил фото и текст; двойной клик принял один ответ на №5 и оставил попытку активной.
- Исправление принятого ответа и явная отправка без фото после неподдерживаемого HEIC; фото не удалялось до успешной новой отправки.

- Отдельно после сбоя перехода и reload кнопка «Камера» открыла выбор файла сразу из состояния ошибки; выбранное фото сохранилось, отсчёт возобновился, обновление ответа с фото прошло успешно без увеличения числа принятых ответов. После отправки время осталось фиксированным.
